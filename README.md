# Zap365 - Your Mobile Device Management Companion

Zap365 is a powerful iOS app designed to manage Windows365 Cloud PCs On the GO. Built with a focus on efficiency and security, it provides a seamless mobile experience for managing your Cloud PCs wherever you are.

## 🌟 Key Features

### Device Management
- View and manage all your Cloud PC from single app.
- Real-time device compliance status
- Detailed device information and specifications
- Quick actions for device management

### Cloud PC Management
- View and manage Windows 365 Cloud PCs
- Monitor Cloud PC health status
- Perform quick actions on Cloud PCs


### User-Centric Design
- Beautiful and intuitive interface
- Dark mode support
- Quick actions for common tasks
- Offline capability with demo mode

## 🔐 Security & Privacy

- Secure authentication with Microsoft Entra ID
- No data storage on device
- End-to-end encryption
- Compliance with enterprise security standards

## 📱 System Requirements

- iOS 17.6 or later
- Valid Microsoft Intune license
- Microsoft Entra ID account with appropriate permissions

## 🔄 Demo Mode

Try out Zap365's features without connecting to a real Intune environment:
- Access mock device data
- Test management features
- Explore the interface risk-free
